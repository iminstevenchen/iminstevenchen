## Selected projects

### [CRC-ORACLE](https://github.com/iminstevenchen/crc-oracle)

I built the bilingual interface for a research demo that combines similar-patient cohort search with survival and postoperative outcome visualizations. I worked with clinical and data science teammates who developed the modeling methods. The demo uses 12,196 synthetic records for research exploration; it isn't intended for individual diagnosis or treatment decisions.

[Live demo](https://crc-oracle.vercel.app)

### [Cz landmark estimation for fNIRS](https://github.com/hpphearscode/fNIRS-emotion-VandyBH26/pull/14)

I designed a C7-referenced protocol for new participants and outlined a residual-correction approach for existing data using head-shape and cap-fit features. Only four participants had confirmed Cz markers, so the work remains a descriptive pilot; we did not claim a fitted model.

### Parent Navigator

I managed a LINE and web assistant for families in Taiwan with children ages 0–3. I built the LINE service and helped integrate retrieval-based guidance on parenting benefits and health information. The project uses Flask, Gemini, LangChain, and Supabase. [Code](https://github.com/iminstevenchen/LineBot) · [Project repository](https://github.com/iminstevenchen/Parent-Navigator) · [Demo](https://parent-navigator.vercel.app/)

### [Nurse Resiliency](https://github.com/iminstevenchen/nurse-resiliency)

A methods project on burnout-risk modeling across 6,000+ medical providers, using sentence-transformers, clustering, and XGBoost. The data can't be shared, so the repository contains methods and no participant records.
